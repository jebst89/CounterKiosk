# TARGET: Raspberry Pi Zero W (original, single-core ARMv6) on Raspberry Pi OS.
#
# IMPORTANT for the Zero W: prefer the system packages for pygame and the lgpio
# backend rather than building wheels from source. On ARMv6, `pip install
# pygame` frequently tries to compile from source and is slow or fails. Install
# these via apt instead (see README), then create the venv with
# --system-site-packages so it can see them:
#
#   sudo apt install -y python3-pygame python3-lgpio
#   python3 -m venv --system-site-packages .venv
#   .venv/bin/pip install -r requirements.txt
#
# With python3-pygame installed via apt and visible through
# --system-site-packages, pip will not need to build it. gpiozero is pure
# Python and installs cleanly from pip on ARMv6.
